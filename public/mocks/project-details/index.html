the problem

Social platforms turn a simple shared clip into a detour. Guenther recognizes supported links and returns the underlying media directly to the conversation.

system shape

Telegram updates enter a small router. Media requests cross a private Cobalt sidecar. Bingo commands enter a separate domain model backed by SQLite, and voice capture uses ffmpeg only when its feature is enabled.

what this demonstrates

The project combines asynchronous integrations, persistent state, generated images, strict Rust lints, and a reproducible container deployment without hiding its operational requirements.
