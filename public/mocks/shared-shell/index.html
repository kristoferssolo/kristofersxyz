guenther

A local-first terminal chat client built around Telegram, with messages and media stored on the user's machine.

Why it exists

Telegram is useful, but the official clients keep the archive and the interface coupled to the service. Guenther separates those concerns.

System shape

A Rust client receives updates, stores them locally, and exposes a terminal interface over the same typed model.
